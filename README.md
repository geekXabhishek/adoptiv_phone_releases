# adoptiv_phone_releases

Public release mirror for the Adoptiv mobile and desktop softphone.

The Flutter source repo is private. Tagged builds (`v*`) are mirrored here so
the in-app updater can fetch them via the unauthenticated GitHub API.

Each release attaches:

- `adoptiv-android-vX.Y.Z.apk` — Android APK
- `adoptiv-macos-vX.Y.Z.dmg` — macOS disk image
- `adoptiv-windows-vX.Y.Z.zip` — Windows release folder

Install instructions and changelogs are on the per-release pages.
